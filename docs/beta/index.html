Steam Link VR for the original Oculus Quest

Valve's Steam Link VR app doesn't run on the Quest 1. This page patches the copy that comes with your own SteamVR install and installs it on your headset. Everything happens in your browser; nothing is uploaded.

This browser can't talk to the headset over USB. Use Chrome, Edge, Brave or another Chromium browser on a computer. You can still patch the app here and install the download with SideQuest.

Before you start

  • Turn on developer mode for the headset. You need a Meta developer account in a verified developer organization; then, in the Meta Horizon phone app: headset icon → your headset → Headset Settings → Developer Mode → on. Full steps: Meta's guide.
  • Use a data USB-C cable; charge-only cables don't work.
  • Windows only: install Meta's Oculus ADB Drivers (unzip, then right-click android_winusb.inf → Install).

Meta no longer supports the Quest 1. If the Developer Mode switch doesn't appear for yours in today's Horizon app, please open an issue.

3Install on the headset

With developer mode on (see Before you start), plug the headset into this computer with USB and put it on.

  • Close SideQuest and any other adb first (run adb kill-server); only one program can talk to the headset at a time.
  • The headset will ask to allow USB debugging from this browser. Tick "Always allow".
  • If it also asks to allow access to files, answer that first if you can. Answering it makes the headset reconnect briefly; the page waits for it and carries on.
  • Linux: if the headset doesn't show up in the list, your user may need permission for USB devices (a udev rule for Oculus, vendor ID 2833).
  • Then open Steam Link from Unknown Sources on the headset, pair with your PC, start SteamVR and connect.

Optional: wired streaming over USB

Only for rooted headsets with Magisk. The Quest 1 can't do Steam Link's wired mode by itself: its USB network mode is locked away. On a headset with an unlocked bootloader, root and Magisk installed, a small Magisk module from this project turns it on, and Steam Link then streams over the cable with Wi-Fi as a backup (or the cable alone with Wi-Fi off). Wireless streaming works without any of this.

  • Needs: an original Quest on its final firmware, bootloader unlocked (e.g. with QuestStack, which wipes the headset), Magisk installed, and the patched Steam Link from above.
  • Your PC needs no setup: the headset gives it its address on the cable automatically. Tested streaming from SteamOS; Windows should work (it has the USB network driver built in) but is untested.
  • The module sets the headset's cable address to 10.86.13.37 and the PC's to 10.86.13.38. Remove it any time in the Magisk app (Modules), then restart.

What it changes

  • Supported devices: the Quest 1 crashes on device names it doesn't know ("quest3"), so the app's device list is cut down to names it knows.
  • Display 0: on the Quest 1 the VR part of the app opens on the 2D window's hidden screen and never shows. A small extra class added to the app opens it on the main display instead.
  • Quest 1 identity: SteamVR sees an "Oculus Quest" with Quest 1 Touch controllers.
  • Wired streaming: if the headset has the USB network from the module above, the stream starts on the cable. Without it, nothing changes.

Valve's own code isn't modified. After a SteamVR update, patch the new app again; it installs over the old one and keeps your pairing.

Every patched app is signed with the same, deliberately public key (signing-key.pem), so updates install in place from any computer. The trade-off: anyone could sign an app with it, so only install Steam Link builds you made yourself.

Known issues
  • Wired (USB) streaming needs a rooted headset with Magisk and the module above; stock headsets stream over Wi-Fi only.
  • A minimized 2D window sometimes won't come back (a Quest 1 system bug). Reboot the headset, or run adb shell am force-stop com.oculus.vrshell.

Problems? Open an issue and include the log above.
